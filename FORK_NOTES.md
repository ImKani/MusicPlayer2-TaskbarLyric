# MusicPlayer2-TaskbarLyric

This is a personal fork of MusicPlayer2.

It adds:

- Shared-memory lyric IPC for a TrafficMonitor taskbar lyric plugin.
- Same-timestamp parallel lyric line handling.
- A lyric settings UI option for selecting which parallel line is used as the original MusicPlayer2 translation line.
